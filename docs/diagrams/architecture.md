# Arquitetura do Sistema - Plataforma de Streaming

## 📚 Índice de Diagramas

Este documento organiza todos os diagramas de arquitetura do sistema. Cada diagrama está disponível em um arquivo `.mermaid` separado na pasta `diagrams/` para facilitar manutenção e visualização.

3. [**Fluxo de Criação de Stream**](diagrams/03-fluxo-criacao-stream.mermaid) - Processo de criação de transmissão
4. [**Fluxo de Transmissão**](diagrams/04-fluxo-transmissao.mermaid) - Do OBS aos espectadores
5. [**Fluxo de Visualização**](diagrams/05-fluxo-visualizacao.mermaid) - Como espectadores assistem

7. [**Estrutura de Pastas**](diagrams/07-estrutura-pastas.mermaid) - Organização do projeto
8. [**Alternativas Tecnológicas (Mindmap)**](diagrams/08-alternativas-mindmap.mermaid) - Mapa de opções
9. [**Estados da Stream**](diagrams/09-estados-stream.mermaid) - Máquina de estados
10. [**Fluxo de Métricas**](diagrams/10-fluxo-metricas.mermaid) - Coleta e monitoramento
11. [**Pipeline de Deployment**](diagrams/11-pipeline-deployment.mermaid) - Build e deploy

## 📖 Como Usar

Para visualizar os diagramas:
1. Abra os arquivos `.mermaid` no VS Code com a extensão Mermaid Preview
2. Ou use ferramentas online como [Mermaid Live Editor](https://mermaid.live)
3. Ou use a ferramenta de visualização integrada do GitHub
