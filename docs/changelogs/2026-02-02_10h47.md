# Changelog - 2026-02-02 10h47

## Task: Externalizar Configurações do Docker Compose para .env

### Objetivo
Mover todas as configurações hardcoded do `docker-compose.yml` para variáveis de ambiente em arquivos `.env`, seguindo as melhores práticas de segurança e portabilidade.

---

## 🎯 Problema Resolvido

### Antes
- Credenciais e configurações hardcoded no `docker-compose.yml`
- Valores não podiam ser alterados facilmente
- Risco de commitar senhas no Git
- Difícil gerenciar múltiplos ambientes (dev/staging/prod)

### Depois
- ✅ Todas as configurações em `.env`
- ✅ `.env.example` como template
- ✅ `.env` já estava no `.gitignore`
- ✅ Fácil gerenciar múltiplos ambientes

---

## 📦 Arquivos Criados

### 1. `/.env`
**Propósito**: Configurações reais do ambiente

**Conteúdo**:
```env
# Database
POSTGRES_DB=streaming_db
POSTGRES_USER=streaming_user
POSTGRES_PASSWORD=streaming_pass
POSTGRES_PORT=5432

# Redis
REDIS_PORT=6379
REDIS_MAXMEMORY=512mb
REDIS_MAXMEMORY_POLICY=allkeys-lru

# RabbitMQ
RABBITMQ_USER=streaming_user
RABBITMQ_PASSWORD=streaming_pass
RABBITMQ_PORT=5672
RABBITMQ_MANAGEMENT_PORT=15672

# Backend
BACKEND_PORT=8080
SPRING_PROFILES_ACTIVE=docker
```

**Segurança**:
- ❌ Não versionado no Git (já está no `.gitignore`)
- ✅ Contém valores padrão para desenvolvimento local

### 2. `/.env.example`
**Propósito**: Template de configuração (versionado no Git)

**Diferenças do .env**:
- Valores são placeholders: `your_database_password`
- Serve como documentação das variáveis necessárias
- Qualquer pessoa pode copiar e configurar

**Uso**:
```bash
cp .env.example .env
nano .env  # Editar com valores reais
```

## 🎓 Aprendizados Técnicos

### Docker Compose Environment Variables
- Carrega automaticamente `.env` da raiz
- Sintaxe: `${VARIABLE_NAME}`
- Pode sobrescrever com `--env-file`

### Twelve-Factor App
- Config como variáveis de ambiente
- Separação de código e configuração
- Facilita deploy em múltiplos ambientes

### GitIgnore Patterns
- `.env` - Ignora arquivo específico
- `*.env` - Ignora todos .env.*
- `!.env.example` - Exceção (não ignora)
